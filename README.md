# Backend Roadmap Guide

A single-page field manual for a Java / Spring Boot developer moving into a backend engineer role (Mumbai IT market).

**Contents**
- 18 groups of backend concepts, with diagrams and syntax-highlighted code examples
- Aptitude practice (55 questions), practical/technical test questions, and 33 LeetCode-style problems with Java solutions
- A 4-round mock interview script (HR, technical, hiring manager, offer)
- Role guide (job description, Mumbai salary ranges, tech stack, products, industries) with tailored resumes

**Files**
- `index.html` — the full guide (self-contained, open directly in a browser)
- `resumes/` — 5 ATS-friendly resume variants, each as `.docx` and `.pdf`
